--- Example: Pod with stress Command
Here’s an example of a Kubernetes Pod that uses the stress command to consume CPU and memory:

yaml
Copy
apiVersion: v1
kind: Pod
metadata:
  name: stress-pod
spec:
  containers:
  - name: stress-container
    image: polinux/stress
    args:
    - "--cpu"
    - "2"
    - "--vm"
    - "1"
    - "--vm-bytes"
    - "128M"
    resources:
      limits:
        cpu: "500m"
        memory: "256Mi"
      requests:
        cpu: "250m"
        memory: "128Mi"
Explanation of the stress Command
The stress command in the example above has the following arguments:

--cpu 2: Spawn 2 workers to stress the CPU.

--vm 1: Spawn 1 worker to stress the memory.

--vm-bytes 128M: Allocate 128 MB of memory per worker.

--- Common stress Command Options
--- gHere are some common options for the stress command:

Option	Description
--cpu N	Spawn N workers to stress the CPU.
--vm N	Spawn N workers to stress the memory.
--vm-bytes SIZE	Allocate SIZE bytes of memory per worker (e.g., 128M, 1G).
--io N	Spawn N workers to stress the I/O.
--hdd N	Spawn N workers to stress the disk by writing and removing files.
--timeout SEC	Run the stress test for SEC seconds and then exit.
